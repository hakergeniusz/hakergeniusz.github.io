# hakergeniusz.github.io

A single-page, brutalist portfolio for [hakergeniusz](https://github.com/hakergeniusz). Plain HTML, CSS and JavaScript, no build step.

## Features

- Brutalist design with a custom yellow scrollbar, smooth anchor scrolling, a scroll progress bar and GSAP-style scroll-triggered reveal animations (respects reduced motion)
- Light/dark theme toggle (remembers your choice) and a TRUE dark mode easter egg: hold the theme button for 3 seconds, click again to switch back
- Round avatar with a clean border, no decorative frame (click it to poof it, click again to restore; hold it for 3 seconds for a 5-second rickroll with a 180-degree flip)
- Two more easter eggs: 10 seconds after poofing the avatar a pixel-art Pac-Man spawns at the avatar spot, keeps walking toward WASD/arrow/swipe direction (on-screen D-pad on mobile, where the page stays scrollable) and eats UI text with a chomp effect and progress bar (Escape restores everything including the avatar), or type `PACMAN` after poofing the avatar to trigger it instantly
- Live repo list from the GitHub API with a built-in snapshot fallback
- Search, language filters and sorting for the repo grid; searching `play-bad-apple` or typing `BADAPPLE` anywhere plays the ASCII Bad Apple animation with audio
- Token usage heatmap fetched live from GitHub on every load and restyled to match the current theme (local snapshots as offline fallback)
- LOC contributed metric generated from real GitHub commit data
- Links to GitHub, Discord (`@hakergeniusz`) and X/Twitter (`@hakergeniusz`)
- Click-to-copy handles, MIT license

## Run locally

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000>. Opening `index.html` directly also works, but the live GitHub data fetch is more reliable over HTTP.

## Deploy

Push the files to the `main` branch of your `hakergeniusz.github.io` repository, then enable GitHub Pages from **Settings - Pages - Deploy from a branch - main / root**. No build command needed.

## Data sources

| Item | Source |
| --- | --- |
| Repos, stars, languages | GitHub REST API `/users/hakergeniusz/repos`, with a static fallback in `main.js` |
| Token heatmap | `https://raw.githubusercontent.com/hakergeniusz/hakergeniusz/data/token-heatmap.svg`, restyled into `assets/token-heatmap-{light,dark}.svg` |
| LOC contributed | `assets/loc-data.json`, generated by `scripts/count-loc.py` from GitHub `stats/code_frequency` |

### Refreshing the heatmap

`assets/token-heatmap-light.svg` and `assets/token-heatmap-dark.svg` were generated from the upstream SVG by replacing its style block with the brutalist palette and square corners. Regenerate them whenever the upstream data changes.

### Refreshing the LOC number

```sh
# Anonymous: GitHub allows 60 requests/hour, so a subset of repos is measured.
uv run scripts/count-loc.py

# With a personal token for full coverage and higher limits:
GITHUB_TOKEN=ghp_xxx uv run scripts/count-loc.py
```

The script writes `assets/loc-data.json`. It sums weekly line additions from GitHub's `stats/code_frequency` for the largest non-fork public repos. Deletions are tracked separately. GitHub includes all contributors to those repos, so treat the number as "lines added across this account's projects", not a strict personal-only count. The number on the site shows a `--` placeholder until the JSON file exists.
